# Project Roadmap

1. Requirements/research: confirm scope, research gap, labels, dataset license and ethics.
2. UI prototype: responsive frontend with mock data clearly labelled.
3. Backend foundation: auth, DB, migrations, API, ownership and privacy controls.
4. AI baseline: dataset, annotation, classifier, strategy rules and generation adapter.
5. Integration/evaluation: connect layers, test security, evaluate model and usability.
6. Optional extension: demo-page adapter, narrow permissions, explicit user activation, no auto-send.
7. Finalization: fix defects, document limitations, prepare demo/report.

Do not start real-platform extension integration before terms/policy and technical review.
