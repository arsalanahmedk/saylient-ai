# Accessibility Requirements

- Semantic landmarks and heading hierarchy.
- Programmatic labels for all controls.
- Keyboard-only operation and visible focus.
- Logical focus order; dialogs manage focus and support Escape.
- WCAG 2.2 AA contrast targets.
- Do not communicate meaning by color alone.
- Respect reduced-motion preferences.
- Associate validation errors with fields.
- Test with keyboard and a screen reader before release.
