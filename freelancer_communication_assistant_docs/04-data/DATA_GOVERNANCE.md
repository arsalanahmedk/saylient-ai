# Data Governance and Privacy

## Data classes
Account data; user messages/context/drafts; derived labels and scores; operational metadata.

## Collection
Collect minimum data. Explain storage before submission. Do not collect credentials, cookies or unrelated browsing activity. Do not use user content for training by default.

## Dataset sources
Use public corpora only after license/suitability review, clearly tagged synthetic examples, and consented participant examples. Do not use private platform conversations without permission. Track source, license, consent, date and transformations.

## Retention
Define retention separately for raw content, derived analyses, logs and backups. Provide deletion/export. Explain backup expiry. Keep minimal security events only as justified.

## External AI providers
Review retention, training, subprocessors and processing region. Send minimum necessary text. Never send passwords, session tokens or irrelevant identifiers.

## Research ethics
Obtain informed consent, anonymize examples, explain limitations and do not imply model outputs are objectively correct.
