# User Stories

- As a freelancer, I want to set a boundary about extra revisions without sounding hostile.
- As a freelancer, I want to request overdue payment clearly and professionally.
- As a freelancer, I want to negotiate a deadline while preserving the relationship.
- As a freelancer, I want the tool to explain why it recommended a strategy.
- As a user, I want to edit a generated response before copying it.
- As a user, I want to delete my message history.
- As a user, I want missing context to be shown as unknown rather than guessed.
