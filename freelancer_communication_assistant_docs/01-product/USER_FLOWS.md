# User Flows

## Analyze
Sign in → Message Assistant → paste message → optionally add prior context → choose goal and known context → analyze → review labels and uncertainty → edit draft → copy/save/discard.

## Missing context
Submit with missing P/D/R → system marks unknown → optionally asks a focused clarification → never infers context from protected traits or stereotypes.

## Delete history
Open History → select item → confirm → server checks ownership → delete → confirm only after success.

## Future extension
Open extension on supported demo chat → explicitly enable → read visible messages in active conversation → analyze selected message → review/edit draft → user chooses Copy or Insert. No auto-send.
