# Freelancer–Client Communication Assistant — Documentation Pack

This pack is the documentation baseline for the proposed English-first FYP web application. It covers product requirements, software requirements, UX, architecture, security, threat modelling, data, AI/ML, APIs, engineering, testing, deployment and project delivery.

## Assumptions
- Web application is the primary product; browser extension is a separate later deliverable in `extension/`.
- Prototype deployment; team of three; free/low-cost cloud resources.
- Hybrid AI: classifier + explicit Politeness Theory strategy engine + LLM response drafting.
- English-only MVP.
- Suggestions are always reviewed by the user. The app never sends messages automatically.
- Demo/mock results must be visibly labelled until real backend/models are integrated.

## Document map
- `01-product/`: PRD, SRS, user stories, use cases and user flows.
- `02-architecture/`: system, software, deployment and security architecture; threat model; ADRs.
- `03-ux/`: design system, screen specification and accessibility.
- `04-data/`: data dictionary, database design and privacy/data governance.
- `05-ai-ml/`: AI pipeline, dataset, annotation and evaluation plans.
- `06-api/`: API specification and error conventions.
- `07-engineering/`: frontend/backend conventions, repository structure, testing, CI/CD, deployment, monitoring, backup and incident response.
- `08-project/`: roadmap, team roles, risks and traceability.
- `09-operations/`: user support, release checklist and maintenance.

## Status
These are proposed design documents, not evidence that the system has been implemented, tested, security-certified, or approved by a freelance platform. Update the documents as decisions change.
