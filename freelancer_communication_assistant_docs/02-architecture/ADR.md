# Architecture Decision Records

## ADR-001 — Hybrid AI
**Status:** Proposed. Use supervised classifier + explicit politeness strategy engine + LLM drafting. This separates measurable prediction from theory-based rules and language generation.

## ADR-002 — English-only MVP
**Status:** Proposed. Limit initial annotation and evaluation to English.

## ADR-003 — Human approval
**Status:** Proposed. Suggestions remain editable; user copies/inserts manually. No auto-send.

## ADR-004 — Separate extension
**Status:** Proposed. Keep extension code, manifest, permissions and build separate from web app.

## ADR-005 — Replaceable model providers
**Status:** Proposed. Use interfaces/adapters so model vendors can be replaced without changing product/domain logic.
