# Frontend Engineering Guide

- React + TypeScript + Vite + Tailwind.
- TypeScript strict mode.
- Keep API calls in service modules.
- Validate forms client-side for UX and server-side for security.
- Use semantic HTML and accessible labels.
- Do not store passwords, provider keys or long-lived tokens in localStorage.
- Render pasted text as text; avoid unsafe HTML.
- Provide loading, empty, success and error states.
- Use a central API client with timeouts and safe error handling.
- Keep demo/mock mode clearly labelled and isolated from production.
