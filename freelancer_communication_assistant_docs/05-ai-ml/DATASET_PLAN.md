# Dataset Plan

## Proposed project dataset
Freelancer–Client Politeness and Communication Dataset (FCPD). This is a proposed project-created dataset name, not an existing established corpus.

## Sources
- Public datasets after license and suitability review.
- Synthetic examples tagged as synthetic.
- Consented examples written by participants/domain-informed annotators.
- No private platform chats without permission.

## Annotation fields
Message/context; intent; tone; FTA present/absent/uncertain; face concern; P/D/R or unknown; strategy label(s); source type; pseudonymous annotator; adjudication status.

## Process
Write handbook → pilot annotation → double-annotate subset → calculate inter-annotator agreement → adjudicate disagreements → split by conversation/source to reduce leakage → preserve source/license metadata.

## Limitations
Report small sample size, class imbalance, cultural/domain coverage and synthetic-data proportion. Do not claim broad generalization without evidence.
